# UX Audit Skill

## Finalidade
Identificar problemas de usabilidade, sobrecarga cognitiva e fricções visuais em cada tela do sistema Q.I. Tech.

## Responsabilidades
1. Avaliar cada tela sob os três pilares de clareza:
   - Onde estou?
   - Qual a informação mais importante?
   - O que posso fazer agora?
2. Detectar concorrência entre chamadas para ação (CTAs) e assegurar uma única ação primária por contexto.
3. Identificar informações essenciais (Nível 1) versus complementares (Nível 2 — Progressive Disclosure).
4. Localizar textos repetidos, jargões técnicos excessivos e badges decorativos desnecessários.
5. Produzir e atualizar a matriz de auditoria com problemas classificados por impacto.

## Checklist de Execução
- [ ] Mapear todos os elementos visíveis da tela.
- [ ] Verificar se há mais de 1 CTA primário disputando atenção.
- [ ] Verificar se há jargões de backend (ex: nomes de endpoints, IDs de banco, siglas internas).
- [ ] Avaliar se os cards contêm entre 3 e 5 informações prioritárias.
- [ ] Confirmar que dados detalhados estão ocultos sob demanda (disclosure).
