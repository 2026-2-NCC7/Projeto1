## 💡 1. Visão Geral do Produto

O **Q.I. Match** é uma plataforma de engenharia de software desenvolvida como Trabalho de Conclusão de Curso (TCC) em Ciência da Computação pela **FECAP**. 

O projeto soluciona de forma definitiva os gargalos estruturais das plataformas tradicionais de recrutamento técnico (ATS legados):
1. **Opacidade Algorítmica:** Candidatos são descartados por "filtros de palavras-chave" ou caixas-pretas estatísticas sem qualquer justificativa técnica (infringindo o Art. 20 da LGPD);
2. **Falta de Privacidade e SPAM:** Telefones, e-mails e histórico pessoal são distribuídos sem critério para bancos de dados corporativos;
3. **Assimetria Salarial:** Vagas omitindo faixas salariais e forçando candidatos a passarem por semanas de etapas antes de saber a remuneração;
4. **Desconexão entre Currículo e Habilidade Real:** Currículos inflados artificialmente superam talentos práticos que não dominam técnicas de SEO para ATS.

A resposta do **Q.I. Match** é um ecossistema unificado onde **a IA avalia evidências empíricas de áudio e código**, as **empresas disputam profissionais já qualificados** e os **dados pessoais permanecem confidenciais** até a autorização mútua.

## ⚖️ O Paradigma Q.I. Match vs. Recrutamento Convencional

<div align="center">

| Dimensão Crítica | Plataformas Convencionais (Gupy, LinkedIn, Catho) | Q.I. Match (Recrutamento Invertido) |
|:---|:---|:---|
| **Modelo Operacional** | Candidato envia dezenas de currículos e aguarda passivamente | **Invertido:** O radar ativo posiciona o candidato para receber propostas diretas |
| **Avaliação Técnica** | Triagem rasa por string matching em PDFs e testes genéricos | **Entrevista Técnica Estruturada:** Áudio real via Whisper + extração de evidências literais |
| **Explicabilidade** | "Reprovado no fit cultural" sem dados (Caixa-Preta) | **Transparência Algorítmica:** Score decomposto em 5 dimensões e pesos visíveis |
| **Privacidade do Candidato** | PII exposta para múltiplos recrutadores sem controle | **Double Opt-In Estrito:** Identidade 100% anônima até confirmação mútua |
| **Direito de Defesa (LGPD)** | Inexistente; recusa final automatizada sem recurso | **Art. 20 LGPD Nativo:** Contestação formal com versionamento auditável (`v1 → v2`) |
| **Experiência do Candidato** | Cliques acidentais ou desistências encerram o processo | **Guarda contra Cliques Acidentais:** Popups de confirmação em 2 etapas |
| **Remuneração Declarada** | "Salário a combinar" ou faixas ocultas | **Transparência Salarial Obrigatória:** Piso e teto declarados em 100% das vagas |

</div>

## 🛡️ Camada de Segurança, Cibersegurança & LGPD

A segurança da informação foi implementada sob a filosofia de **Defesa em Profundidade (*Defense in Depth*)**:

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ 🔐 MATRIZ DE SEGURANÇA & MITIGAÇÃO DE VULNERABILIDADES                                  │
├──────────────────────────────┬──────────────────────────────────────────────────────────┤
│ VETOR DE AMEAÇA              │ MECANISMO DE DEFESA IMPLEMENTADO NO Q.I. MATCH           │
├──────────────────────────────┼──────────────────────────────────────────────────────────┤
│ Ataques de Força Bruta       │ Bloqueio progressivo (30s / 60s / 120s) persistido em  │
│ (Brute-Force Login)          │ cookies e localStorage (imune a F5/recarregamento)       │
├──────────────────────────────┼──────────────────────────────────────────────────────────┤
│ Roubo de Sessão e PII        │ Ticket Magro (Lean Session Token): cookie HttpOnly com   │
│ (Session Hijacking)          │ identificador anônimo volátil e bandeira SameSite=Strict│
├──────────────────────────────┼──────────────────────────────────────────────────────────┤
│ Sequestro de Clique          │ Proteção Anti-Clickjacking: interrupção de renderização  │
│ (Clickjacking / Phishing)    │ caso a aplicação seja encapsulada em iframes externos    │
├──────────────────────────────┼──────────────────────────────────────────────────────────┤
│ Injeção de Comandos na IA    │ Sanitização prévia e encapsulamento em blocos literais;  │
│ (Prompt Injection)           │ o motor ignora instruções de bypass e pontua fatos reais│
├──────────────────────────────┼──────────────────────────────────────────────────────────┤
│ Violação da Privacidade     │ Double Opt-In obrigatório: dados nominais ocultos até    │
│ (LGPD Art. 20)               │ autorização expressa; banner de consentimento de cookies │
├──────────────────────────────┼──────────────────────────────────────────────────────────┤
│ Erros Acidentais de Ação     │ Modais de confirmação progressivos em cancelamentos      │
│ (Accidental Click Bypass)    │ de processos seletivos e recusas de convites              │
└──────────────────────────────┴──────────────────────────────────────────────────────────┘
```

> [!IMPORTANT]
> **Privacidade Absoluta por Design:** Nenhuma gravação de áudio ou texto de resposta do candidato é enviado para APIs externas comerciais (OpenAI, Anthropic, Google). O processamento ocorre localmente na máquina servidora.

## 💻 Guia de Inicialização Rápida (1 Minuto)

### Pré-requisitos
* **Node.js** v18+ ou v20+
* **Python** 3.11 ou 3.12
* **Git** instalado

### Inicialização em 1 Clique (Windows)
Na pasta do projeto, execute o arquivo de lote:
```powershell
.\run_all.bat
```
Este utilitário inicializa de forma concorrente a API FastAPI na porta `8000` e a aplicação React/Vite na porta `5173`.

---

### Inicialização Manual por Terminal

<details>
<summary><strong>Passo 1: Backend FastAPI (Python)</strong></summary>

```powershell
# 1. Acesse o diretório do backend
cd backend

# 2. Crie e ative o ambiente virtual
python -m venv ..\venv
..\venv\Scripts\activate

# 3. Instale as dependências
pip install -r requirements.txt

# 4. Inicie o servidor assíncrono
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
* **Endpoint da API:** `http://127.0.0.1:8000`
* **Swagger / Documentação Interativa:** `http://127.0.0.1:8000/docs`
</details>

<details>
<summary><strong>Passo 2: Frontend SPA (React + TypeScript + Vite)</strong></summary>

```powershell
# 1. Na raiz do Projeto1, instale os pacotes npm
npm install

# 2. Inicie o servidor de desenvolvimento Vite
npm run dev -- --host 127.0.0.1 --port 5173
```
* **Aplicação Web:** `http://127.0.0.1:5173`
</details>
