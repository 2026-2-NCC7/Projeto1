Six questions
Before you buy.
The six things people ask before they buy, filed where you can reach them. Pull a tab to read one.
What exactly does the single licence let me do?
Put it on one live domain, and that domain can be a client's. Client work on the single licence is fine as long as it stays one site. If you already know you will use it twice, the unlimited licence costs less than buying twice.
Is the Figma file included?
Yes, in both licences, and it is the file the site was drawn in rather than a redraw made afterwards. Colours and type are Figma variables mapped one to one onto the CSS custom properties, and the components are components, with their states as variants.
Will it move to React, Astro or Webflow?
The markup is plain HTML with no framework assumptions and the CSS is custom properties, so porting is mechanical rather than interpretive. Working Astro and Next ports are in the download. It is not a Webflow template and it will not import into Webflow cleanly, so do not buy it for that.
What happens when you update it?
Fixes and new components for this version are free for as long as the version exists, and arrive as a download link by email. If there is ever a version two it will be a paid upgrade at half price, and it will be a genuinely different system rather than this one with the spacing changed.
Can I get a refund?
Within fourteen days, without explaining yourself, even though you have already downloaded it. The one thing to know is that if you have shipped a client site on it, take the unlimited licence rather than the refund, because a refund cancels the licence that site is running under.
What support is there?
Email, answered by the person who made it, usually inside a working day. It covers the template — the files, the ports, the Figma. It does not formally cover your build, though in practice that line has never once been the end of a conversation.
